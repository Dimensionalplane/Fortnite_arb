# IDEAS

## Feature Expansions
- Support for CS2, Dota 2, and TF2 skins.
- Real-time price alerts via Discord or Telegram.
- Integration with third-party marketplaces (Skinport, DMarket).

## Technical Improvements
- Use asynchronous fetching (`aiohttp`) for high-performance scanning.
- Implement a database (SQLite or PostgreSQL) for historical price tracking.
- Dockerize the application for easier deployment.
